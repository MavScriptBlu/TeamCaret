## Folder Structure (in codebase)

```
frontend/
├── Components/     # Reusable Blazor components
├── Pages/          # Page-level components (routed)
├── Services/       # HTTP clients and business logic
├── Shared/         # Shared layouts and nav
└── wwwroot/        # Static assets
```
